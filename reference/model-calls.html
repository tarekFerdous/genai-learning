Messages

from langchain.messages import SystemMessage, HumanMessage, AIMessage
messages = [SystemMessage("rules + context"), HumanMessage("question")]

Stateless: to continue a conversation, append the AIMessage and the next HumanMessage, then send the whole list again.

Call it

model.invoke(messages)→ one AIMessage
model.stream(messages)→ iterator of chunks (chunk.content)
model.batch([m1, m2])→ list of AIMessage, run in parallel
resp.contentthe text
resp.usage_metadatainput_tokens, output_tokens, total_tokens

# Mission: Production-Grade GenAI (RAG, LangChain, LangGraph)

## Why
Land an AI Engineer role. Build one deployed, production-grade RAG/agent system that I understand end to end, so I can put it on my CV, LinkedIn and portfolio site and defend every design decision in an interview.

## Success looks like
- I can build a RAG pipeline from scratch (load → chunk → embed → store → retrieve → generate) without copying a tutorial, and explain why each step exists.
- I can build stateful agents in LangGraph (tools, routing, memory, human-in-the-loop) and say when a graph beats a plain chain.
- I can measure quality with an eval set (retrieval + generation metrics) and show a before/after number for each improvement.
- My capstone is live at a public URL, with an API, streaming, observability, tests/CI, Docker, and guardrails, and a README that tells the story with metrics.
- I can answer "how would you make this production-ready?" with concrete trade-offs.

## Constraints
- Python. ASAP but no hard deadline; prefer learning by doing over watching.
- Hardware: Ryzen 7 9800X3D, 32 GB RAM, RTX 5070 Ti (16 GB VRAM) → local models viable for dev.
- Budget: keep API spend small; use local models for iteration, frontier APIs where quality/deployment needs it.

## Out of scope (for now)
- Training models from scratch / transformer maths.
- Fine-tuning: revisit only if the capstone's evals show prompting + retrieval can't close a gap.
